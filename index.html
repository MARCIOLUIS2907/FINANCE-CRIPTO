    Dados e backup

    Tudo fica salvo neste navegador (armazenamento local). Use backup em JSON para levar os dados para outro aparelho.

    Saldo inicial / ajuste de saldo por corretora

    Use quando você já tinha BTC antes da primeira operação lançada. O saldo inicial entra no cálculo como a primeira compra daquela corretora (afeta saldo, custo médio e P/L). Para o seu caso: informe a corretora, o saldo real e o custo — ou use a calculadora abaixo para achar a diferença.

    Como obter dados das operações

    Para registrar compras e vendas, use a tela da operação, o comprovante ou um screenshot fornecido pela corretora:

    • Registrar operação — formulário rápido com tipo, data/hora, valor, BTC, preço executado, taxa, observação e print opcional.
    • Importar por imagem — lê o screenshot no próprio navegador e mostra os campos para você conferir e corrigir antes de salvar.

    O preço da corretora pode diferir da referência Binance (spread/preço próprio). A análise de P/L considera o preço efetivamente executado na operação.

    Modelo de planilha aceito

    Colunas: Data · Tipo (compra/venda) · BTC · Valor · Cotação · Taxa. Aceita CSV e XLSX, números no formato brasileiro e datas dd/mm/aaaa. Linhas iguais às já existentes são marcadas como duplicadas na prévia.
