Ajuda

De onde tirar os dados para lançar operações e importar planilhas.

Como obter dados das operações

Para registrar compras e vendas, use a tela da operação, o comprovante ou um screenshot fornecido pela corretora:

  • Registrar operação — formulário rápido com tipo, data/hora, valor, BTC, preço executado, taxa, observação e print opcional.
  • Importar por imagem — lê o screenshot no próprio navegador e mostra os campos para você conferir e corrigir antes de salvar.

O preço da corretora pode diferir da referência Binance (spread/preço próprio). A análise de P/L considera o preço efetivamente executado na operação.

Modelo de planilha aceito

Colunas: Data · Tipo (compra/venda) · BTC · Valor · Cotação · Taxa. Aceita CSV e XLSX, números no formato brasileiro e datas dd/mm/aaaa. Linhas iguais às já existentes são marcadas como duplicadas na prévia.

Como publicar no GitHub

Na aba Configurações, o card Publicar no GitHub envia o painel atual para o seu repositório (somente o código — seus dados ficam neste navegador):

  1. Confira o repositório (formato dono/nome) e o branch (geralmente main).
  2. Cole o token e clique em Publicar agora.
  3. Para ver o painel no ar, ative o Pages: no GitHub, Settings → Pages → Deploy from branch → branch main, pasta / (root).

Como conseguir o token

  1. No GitHub, clique na sua foto (canto superior) → Settings → Developer settings → Personal access tokens.
  2. Escolha Fine-grained tokens → Generate new token: dê um nome, defina a validade, selecione apenas o repositório do painel e, em permissões, Contents → Read and write.
  3. Clique em Generate token e copie na hora — ele só aparece uma vez.
  4. Cole no campo de token aqui do painel. Se marcar Manter token neste navegador, ele fica salvo só no seu aparelho.

Nunca compartilhe o token nem cole ele em mensagens ou comentários. Se ele vazar, apague em Settings → Developer settings → Personal access tokens e gere outro.

Ponte finanças

Envia sozinha uma cópia criptografada do backup (operações + saldos iniciais + método) para um canal que o app de finanças lê — até 60 segundos após cada alteração. O canal é cripto-mn1roai4yi7b8knryugs.

  1. Senha: em Configurações → Ponte finanças, digite a senha e clique em Ativar. Ela vive só na memória e some ao recarregar — sem senha, a ponte pausa e nada é publicado. Use a mesma senha dos dois lados.
  2. Chave do canal (editKey): quem cria o canal guarda a chave. Se o app de finanças criou o canal, instale a chave aqui rodando finColarChave() no console e colando-a.
  3. Requisitos: generator salvo e, de preferência, com nome fixo (renomear faz a chave guardada se perder).
