# FINANCE-CRIPTO

Painel de controle de operações de Bitcoin: saldo, custo médio, FIFO, lucro realizado, gráficos e importação de planilha/imagem.

## Uso

- Abra `index.html` no navegador, ou publique com GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
- Sem build — HTML + CSS + JS puro, com Chart.js, SheetJS, Tesseract.js e html2canvas via CDN (sob demanda).

## Abas

Resumo · Operações · Gráficos · Análise · Relatórios · Configurações (backup/restauração + saldo inicial) · Ajuda.

## Dados

Tudo fica no `localStorage` do navegador. Use Backup JSON em Configurações para levar os dados entre aparelhos.
